# htr-tooling

*Working name.* An unofficial, drop-in replacement for [loghi-tooling](https://github.com/knaw-huc/loghi-tooling), the Java "minions" between the stages of the [Loghi](https://github.com/knaw-huc/loghi) handwritten text recognition pipeline. It drives Laypa and Loghi-HTR; it does not replace them.

Status: nothing to install yet. The project starts from a brief, then a specification, then a design.

- [Brief](docs/brief.md): the problem, the users, the scope and the requirements.

Not affiliated with the Loghi maintainers (KNAW Humanities Cluster).
