# Open fixture dataset candidates

*Research for [#4](https://github.com/pslits/htr-tooling/issues/4). Done 2026-11-20. Feeds the fixture-set decision that the brief (§6, §11) leaves to the specification.*

**Question.** Which openly licensed handwritten-text datasets could supply a handful of fixture pages (images committed to this MIT-licensed public repository), ideally 17th-century Dutch? For each: licence, period and language, PAGE ground truth with baselines and text, image size and format, where to get it, and whether Loghi's published models were trained on it.

**Method.** Primary sources only: the Zenodo and DataverseNL records (read through their APIs), the licence texts, Loghi's GitHub repositories, and the configuration files that ship with the published Loghi models on the SURFdrive share. For the larger archives, the zip directories were read with HTTP range requests and a few PageXML files were opened. Nothing was downloaded in full, except the 144 MB VOC PageXML archive. Image sizes are taken from `imageWidth`/`imageHeight` in the sampled PageXML files and from file sizes in the zip directories. A dash (—) in a table cell means "not inspected".

### Licence facts that matter for an MIT repository

- **Nationaal Archief scans themselves** are marked "Publiek domein" or CC0. Attribution is "niet verplicht", though appreciated ([NA open data](https://www.nationaalarchief.nl/onderzoeken/open-data/open-data-archiefinventarissen-en-scans-van-archieven)). The CC BY / BY-SA licences on the Zenodo and Dataverse records cover the published dataset, including the transcriptions and layout.
- **CC BY 4.0** allows reproducing and sharing. On sharing, you must keep the creator credit and copyright notice, refer to the licence, link to the source where reasonably practicable, and say whether you modified the material ([legal code §2(a)(1), §3(a)](https://creativecommons.org/licenses/by/4.0/legalcode.en)).
- **CC BY-SA 4.0** has the same attribution duties. In addition, "Adapted Material" ("translated, altered, arranged, transformed, or otherwise modified") that you share must carry BY-SA or a BY-SA-compatible licence ([legal code §1(a), §3(b)](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en)). Fixture files committed unchanged stay under their own licence next to the MIT code. Edited fixture XML would itself be BY-SA.
- **CC BY-NC(-SA) 4.0** allows sharing "for NonCommercial purposes only" ([legal code §1(k), §2(a)(1)](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode.en)). MIT allows commercial use, so the repository would contain files that a commercial user of the code may not redistribute.

## Implications for htr-tooling

These are the facts the fixture choice depends on. Choosing is the owner's call.

1. **Every openly licensed, 17th-century Dutch, page-level GT set released before 2024 that has text and baselines is in the training data of the published Loghi models.** That covers ijsberg/VOC, REPUBLIC and GLOBALISE. Pages from these sets give the models training-set accuracy. Loghi's own example pages (Laypa tutorial, loghi-tooling tests) come from the same sets.
2. **The three 2025 Nationaal Archief releases (rows 3–5) are newer than every published model** and share no page names with `republic7` or with the published ijsberg split. Row 3 (1576–1796, Staten-Generaal) is the only one dated wholly in the 16th–18th centuries. Two caveats:
   - row 3 shares 40 volumes with `republic7`, so the same scribes may appear in training;
   - the pages behind `republicrandom` and `saa` are unpublished, so full independence cannot be shown.
3. **The baselines in the 2025 NA GT were produced by Laypa.** `<Creator>Laypa</Creator>` appears in every sampled file. The records do not say whether they were corrected by hand, or which Laypa model was used. A test that compares htr-tooling's baselines with these GT baselines would partly compare against Laypa output.
4. **All inspected sets use the PAGE 2013 namespace.** The brief makes 2019 the default output (§4.5), so 2013 → 2019 handling would be exercised on input from the first fixture. The NA 2025 sets have no `Word` elements.
5. **Image weight.** NA scans are 1–8 MB per page (median 3–7 MB; up to 17.6 MB in row 4), and REPUBLIC and Staten-Generaal scans are around 5,000 × 4,000 px or larger. A handful of pages adds tens of MB to git.
6. **Getting single pages.**
   - Zenodo serves range requests (HTTP 206), so single pages can be pulled out of the NA zips (rows 2–5) without downloading 3–12 GB.
   - The VOC GT images (row 1) are only available inside one 18.5 GB `.7z`.
   - GLOBALISE (row 6) has no images at all; its pages would have to come from the NA scans, which are public domain/CC0. Fetching individual NA scans by inventory number was not tested.
7. **Licences.** Rows 1–5 and 9 are CC BY 4.0 (attribution and a note of changes). Row 6 and the current cBAD 2017 are CC BY-SA 4.0 (edits must stay BY-SA). ARletta's licence is contradictory within its own record. Any set used would need a NOTICE/attribution entry next to the existing one for the translated minions (brief §6).
8. **cBAD has no transcriptions,** so it can cover baseline steps but not Loghi-HTR text equivalence.

- The SURFdrive README recommends `generic_new_17_2023_05_25_4channel` ("If you are unsure what to choose"). The Loghi README still suggests `generic-2023-02-15` ([SURFdrive README](https://surfdrive.surf.nl/public.php/dav/files/YA8HJuukIUKznSP/loghi-htr/README.txt), [Loghi README](https://github.com/knaw-huc/loghi/blob/main/README.md)).
